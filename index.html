Hermes Backups

Hermes Backups is a personal-use application for securely backing up files from a privately managed server to Google Drive.

How it works

The application is designed to use Restic for encrypted backups and Rclone to transfer the encrypted data to Google Drive.

Google Drive access

The application requests the Google Drive drive.file permission, allowing it to manage files created or authorised for use with this application.

The application is not a public backup service and does not offer accounts to other users.
