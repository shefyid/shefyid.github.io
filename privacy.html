Hermes Backups - Privacy Policy

Last updated: 11 November 2026

Purpose

Hermes Backups is a private, personal-use application designed to store encrypted server backups in the owner's Google Drive.

Google Drive Permissions

The application requests the Google Drive drive.file permission. This allows it to create and manage files authorised for use with the application.

Data Handling

Backup contents are encrypted locally using Restic before being uploaded to Google Drive through Rclone.

Google authentication credentials are stored privately on the owner's server and are not published on this website.

Data Sharing

The application is intended solely for personal use. It does not sell personal data or provide a public service to third-party users.

Encrypted backups are stored using Google Drive, subject to Google's applicable privacy policies.

Data Retention and Deletion

The owner controls backup retention and can delete stored backups from Google Drive.

Access and Security

The application is designed to use restricted Google Drive permissions and encrypted backup storage.

Contact

For enquiries about this application, contact the repository owner through their GitHub profile.
